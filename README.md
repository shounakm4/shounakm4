## Selected projects

### [FindIT](https://github.com/shounakm4/FindIT) — campus lost and found

A mobile-first web prototype for NUS students to report lost or found items, review possible matches, and manage claims.

- **Work includes:** verified student access, photo uploads, report and claim workflows, and matching that combines text, item attributes, image signatures, and Gemini-generated labels.
- **Engineering focus:** server-side image analysis through Firebase Cloud Functions, shared matching logic with automated tests, and GitHub Actions hosting previews.

`React` `JavaScript` `Firebase` `Gemini API`

[Code & architecture](https://github.com/shounakm4/FindIT#readme) · [Open app — NUS verification required](https://nusfindit.web.app)

### [Stockapp — Market Sense Stock Tracker](https://github.com/shounakm4/Stockapp)

A local web app for exploring US stock momentum, sector strength, and market headlines using free data sources.

- **Work includes:** ranked stock scans, sector comparisons, watchlist reminders, and relevant RSS news feeds.
- **Engineering focus:** a Node.js HTTP API, rule-based scoring with readable reasons, cached market data, bounded concurrent requests, and a Yahoo-to-Stooq data fallback.

`JavaScript` `Node.js` `HTML` `CSS` `REST API` `RSS`

[Code & local setup](https://github.com/shounakm4/Stockapp#readme)

### [Diwali Party Royale](https://github.com/shounakm4/diwali-party-royale) — multiplayer party games

Two browser-based party games designed for a shared host screen and individual phone controllers.

- **Work includes:** room joining, game phases, voting, predictions, scoring, configurable timers, and reconnect recovery.
- **Engineering focus:** a server-authoritative game engine, atomic state updates, private player views, and integration tests for concurrent player actions.

`Next.js` `TypeScript` `Tailwind CSS` `Supabase Realtime` `PostgreSQL`

[Code & design](https://github.com/shounakm4/diwali-party-royale#readme) · [Play the demo](https://diwali-party-royale.vercel.app)
